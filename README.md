# КОНТРАКТ·ГИД

Статический информационный сайт-справочник о военной службе по контракту: выплаты, регионы, специальности, требования, документы, льготы, FAQ и форма заявки.

Структура разделов повторяет типовой сайт этой тематики, визуал и подача — свои: «полевой справочник» (бумажный фон, сетка, моноширинные метки, один сигнальный акцент), светлая и тёмная темы, честные пометки «сверить» у неподтверждённых цифр.

## Запуск

```bash
node build.mjs          # собирает src/ → dist/ (Node 18+, без зависимостей)
npx serve dist          # или любой статический сервер; можно открыть dist/index.html напрямую
```

## Структура

```
assets/
  css/style.css         # все стили, токены цветов в :root (светлая/тёмная тема)
  js/data.js            # ВСЕ цифры и факты: выплаты, регионы, специальности, документы, контакты
  js/main.js            # калькулятор, таблица регионов, фильтры, чек-лист, поиск FAQ, форма
  img/favicon.svg
src/
  partials/             # layout, header, footer, calc (калькулятор), apply (форма заявки)
  pages/                # 8 страниц; первая строка — JSON-мета (title, description, nav)
build.mjs               # сборщик: подставляет {{> часть}} и {{переменные}}
```

## Перед публикацией — обязательно

1. **Сверить цифры в `assets/js/data.js`.** Все значения с `check: true` взяты из неофициальных открытых источников, где данные расходятся. После сверки поставьте `check: false` — пометка «сверить» исчезнет. Таблицу регионов дополнить реальными данными.
2. **Контакты** (`contacts` в `data.js`) — сейчас заглушки.
3. **Форма заявки.** Сейчас `action="#"` — форма только валидируется и показывает «Заявка принята». Укажите в `src/partials/apply.html` URL обработчика (свой бэкенд, Formspree, вебхук в Telegram-бота и т.п.), форма отправит `POST` с `FormData`.
4. **Политика обработки персональных данных** (152-ФЗ) — добавить страницу и ссылку у чекбокса согласия.
5. Обновить `updated` в `data.js` — дата показывается в шапке и подвале.
